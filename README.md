# Keeper - Note Taking App 📝

A simple and interactive note-taking application built with **React** and **Vite**, inspired by Google Keep.

Keeper allows users to create, view, and delete notes through a clean and user-friendly interface.

## ✨ Features

- **Create Notes:** Add notes with a title and content.
- **Delete Notes:** Remove notes when they are no longer needed.
- **Dynamic Interface:** Notes are rendered dynamically using React state.
- **Responsive UI Elements:** Interactive components with Material UI.

## 🛠️ Technologies Used

- React
- JavaScript (ES6+)
- Vite
- Material UI (MUI)
- CSS3
- HTML5

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Navigate to the project folder

```bash
cd project
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal to see the application.
